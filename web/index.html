not connected
how to get the token (one-time, about twenty minutes)
  1. Make the account professional: in the Instagram app, Settings → Account type and tools → Switch to professional account → Creator. Free and reversible; it only adds a category under your name.
  2. Allow tools to read your messages: Settings → Messages and story replies → Message controls → Connected tools → Allow access to messages.
  3. Create a Meta app at developers.facebook.com/apps ↗: Create app → use case “Manage messaging and content on Instagram” (or “Other” → type Business). Leave it in development mode: no review is needed for your own account.
  4. Add the Instagram product → “API setup with Instagram login”. Under Generate access tokens, add your Instagram account (you log in there) and accept the tester invite in Instagram: Settings → Website permissions → Tester invites (or instagram.com/accounts/manage_access ↗).
  5. Generate the token with the permissions instagram_business_basic and instagram_business_manage_messages, copy it, paste it above and press connect. It lasts 60 days; feedel refreshes it by itself while it is used.

What Meta hands over: your conversations, the last 20 messages of each, and shared media as a link. Replies are allowed within 24 hours of the other person's last message; later ones are refused by Meta, not by feedel.
